# Public sanitized OAS snapshot

This independent snapshot contains no original Git history. Real character names have been replaced with placeholders. Private account configuration, logs, runtime ledgers, failure screenshots, diagnostic candidates, personal recognition templates and unreviewed new image templates are excluded.

Use the Agent-oriented README and share_setup.py to initialize your own disabled configuration. Install dependencies in an independent Windows Python 3.10 environment and connect through external OASX. Updates target https://github.com/wuyinghua-bjtu/oas.git; automatic updates, emulator ADB replacement and scheduled backend restarts are disabled by default.

Configure your own accounts and rebuild missing templates before using affected features. The static missing-template report does not cover dynamic asset paths. This is not the fully runnable private installation; fresh-environment installation and real-game/device validation remain separate requirements. Original license and attribution remain applicable.

This revision restores 73 reviewed generic UI templates. Private glyph templates and uncertain images remain excluded; 37 explicitly referenced images are still missing. Review contact sheets are local-only and are not published.
