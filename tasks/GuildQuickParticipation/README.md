# 小号寮活动

独立于寻找协作，限定 oas_leveling。角色和服务器在 OASX 的“小号寮活动 → 寮活账号配置”中设置；每个角色必须先在寻找协作的小号列表中配置。默认名单使用 LOCAL_SUPPORT_001 等本地映射角色。每天 19:00 运行。

每个号处理庭院事务、给本地指定主号点赞和赠送友情点、进入当日寮活动后退出并领取集体任务奖励。庭院事务材料不足记为未完成，不影响其他步骤。逐账号结果保存在 `log/GuildQuickParticipation/oas_leveling/`，使用现有推送配置发送完成或异常汇总。
