# 三窗口觉醒

独立任务 `TripleAwakening`，在 `oas_leveling` 中运行，由同一个 worker 控制三个窗口，避免和寻找协作、寮活动同时操作同一设备。

- 队长：MuMu安卓设备-1。
- 队员：MuMu安卓设备-1-1、MuMu安卓设备-1-2。
- 固定火麒麟十层，三人均确认胜利并返回房间或结算后的邀请界面才计一次，共 15 次。
- 自动从庭院读取三个角色名，再创建私人队伍、邀请两个指定队员。队员接受前核对邀请中的队长名。
- 本次现场确认队长OASPlayer003，两个队员OASPlayer002、OASPlayer001。角色名及编号必须完整匹配；好友选中标记随目标所在行定位。
- 邀请列表找不到队员时，重新确认两个队员的游戏与角色名，队长退回庭院再进入十层建房，最多重新寻找一次；仍找不到则停止。
- 支持中断后续跑本地记录中已确认的胜场，不从零刷满 15 次；每轮另存三个窗口的胜利与结算状态。未确认的战斗不自动计入胜场。
- 任一窗口不明确、角色名不稳定、掉队、体力不足导致无法开战、战斗失败或超时，停止整队，保留失败步骤。不会购买体力或重启游戏。
- 三个窗口的游戏区域须保持 1280×720。启动前手动开机并登录。成员 VM/端口从 MuMuManager 只读信息获取，每次截图和输入校验窗口身份。
- 逐轮记录写入 `log/TripleAwakening/oas_leveling/`；完成和异常通过现有 oas_leveling 推送配置汇总，接受回执不代表微信实际送达。
- 默认不开启，完成后自动关闭本任务，不安排每日重复。旧后台需要重新加载配置模型才能显示新增菜单；不要因此重启正在执行其他任务的后台。
