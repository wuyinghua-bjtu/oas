# 小号单人刷裂变之眼

任务 `EyeAwakening` 默认关闭，使用 `oas_leveling` 中“小号寮活”的服务器和角色名单，并复用寻找协作配置中的账号资料。每个账号先切号、两次核对庭院角色名，再进入探索地图读取当日副本掉落进度。未达到 50/50 时单人挑战火麒麟一层；每场战斗前确认一层红色选中状态，战后返回探索地图连续两次读取进度。只有实读 50/50 才标记该角色完成。

进度记录在 `log/EyeAwakening/oas_leveling/YYYY-MM-DD.json`，与分组觉醒及寮活记录相互独立。每个账号默认最多打 300 场，可在任务选项调整。识别失败、战败、账号不符、跨日或达到场数上限时停止并记录账号和阶段。挑战前先记录待核对状态；中断后如果该标记仍在，必须人工确认战斗及掉落状态，不能自动重打一场。

本任务不会自动接在寮活之后。切号和多账号连续运行需要在活动开放后按实际设备验证；体服单号已进行一场隔离战斗及返回地图的测试，不能等同于正式服多号实测。

每个角色确认 50/50 后，任务进入裂变之眼合成列表，滚动到首尾并读取当前持有的五星、六星数量，使用 `oas_leveling` 的既有通知配置单独推送账号和结果。未能完整确认的数量写作“未识别”，不会按零报告；库存数量是当时持有量，不是本次战斗的掉落星级统计。

记录中 `notification.status=accepted` 表示通知服务已接受，不代表收件设备已收到；`failed` 或 `disabled` 可在下次手动执行时重试。若程序在发送中断，状态记为 `uncertain`，不会自动重复推送，需人工确认。

## 三个独立小号配置

`oas_eye_1`、`oas_eye_2`、`oas_eye_3` 分别绑定三台小号模拟器，每份配置仅保留对应的四个小号账号；全部任务初始关闭。各配置的进度保存在 `log/EyeAwakening/<配置名>/`，互不覆盖。使用前手动启动对应模拟器，并启用对应配置的“小号单人刷裂变之眼”。

第一组与 `oas_leveling` 共用 `MuMu安卓设备-1`。启动新配置前需要停止原配置；设备初始化前会检查其他正在运行的 OAS 配置是否使用同一窗口或端口，冲突时停止。其他配置也应避免在新任务运行期间启动同一模拟器。第二、三台模拟器关闭时不会被该检查自动启动。分组配置仅运行自己的单人任务，不承接原寮活或分组觉醒的调度。
